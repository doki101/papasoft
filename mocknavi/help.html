MockNavi is an Android application designed primarily for developers working with maps, GPS, location-based or position-aware apps, and route planning or navigation systems. It makes the development and testing of such applications easier.

It supports simulated GPS positioning, tracking, simulated movement, navigation, and Bluetooth communication (standard NMEA messages). The app can also work as a Bluetooth GPS simulator based on user-defined locations and movement patterns.

Its features include static and dynamic location simulation (“mocking”), route planning, location search, and calculation of distance and estimated travel time. The simulation parameters let you adjust the vehicle speed. MockNavi can also load GPX files and save planned routes in GPX format.

The app is ad-free and has a clean, intuitive user interface with clear, well-organized screens.

1. First start and required settings

When you launch the app for the first time after installation, a few important settings must be configured. They are essential for the app to work correctly. All of them are described on the screen that precedes the setup, so you only need to follow the instructions.

  • Notifications – Allow.
  • Device location – “While using the app” / Allow. This appears only if location services were disabled during installation.
  • Mock location app – In the phone’s developer settings, select MockNavi as the mock location app.
  • Battery usage – Set to “Unrestricted” in the app settings of the phone.

These settings need to be configured only once, after installation. When they are done, the map and the control elements appear on the screen.

3. Background service and exit

When you launch the app, the user interface appears and a background service starts at the same time. This means that a running route simulation does not stop when you move the app to the background or open another application. The service keeps running even when the app is not visible.

While it runs, a “MockNavi” notification with an EXIT button is shown in the notification bar.

The EXIT button stops the background service, releases all used resources, and closes the application. There are two other ways to exit:

  • Quickly press the Back button twice.
  • Use the “Exit App” command in the app menu.

4. Using the main screen

The main screen shows a map similar to Google Maps, with similar controls. The crosshair in the center of the map marks the current map position. This position is also shown numerically in the lat / lon / zoom box at the top right of the screen (1).

You can move the map, and so change the position, in the usual way by swiping. You can also set a position numerically: long-tap the lat / lon / zoom box (1) and enter the values you want.

5. Static “mocking” (fake location)

When you set a new map position, the app automatically sends it as a “mock position” to the system location service of the device. A blue dot appears at that location to show that the position has been mocked. If Bluetooth NMEA output is enabled in the app settings, the position is also sent to connected devices over Bluetooth.

What is this good for?

The service keeps running in the background, so you can switch to another app after setting the position. For example, select Bora-Bora on the ocean, then switch to Google Maps. It will look as if your phone is located at Bora-Bora, which means your phone location is “mocked”.

Because the app can transmit location data over Bluetooth, it can also act as a Bluetooth GPS device. It sends the simulated position to the connected client as standard NMEA sentences.

Please note: position “mocking” is strictly allowed for testing, research, or learning purposes only!

6. Dynamic “mocking” (simulating movement along a route)

To “travel” along a pre-planned route, plan it in the app by specifying a starting point, an end point, and any intermediate points on the map. Once the route is created, you can simulate a virtual vehicle moving along it. During the simulation the app sends the current GPS position every second to the device’s own location system, or to an external device over Bluetooth.

Step by step

  1. Position the map at the starting point of your route, then tap ADD. The app places a marker at that location.
  2. Move the map to the next waypoint, tap ADD again, and repeat as many times as needed.
  3. After adding all your points (at least two), tap ROUTE. The app generates a route from the points and shows it on the map as a blue line.
  4. Press START to begin the simulation. The virtual vehicle moves from the starting point toward the destination at the speed set in the app settings.
  5. During the simulation you can use STOP, RESUME, PAUSE, or CLEAR.

To simulate a new route, first stop the current simulation (or wait for it to finish), then create the new route and start the movement along it.

While the simulation is running you can use the zoom buttons and the re-center button. The vehicle speed is displayed at the top of the screen. At the bottom you can see the route parameters: total length (km), estimated travel time (based on the speed limits of the road segments), distance traveled (km), and elapsed time.

Important: when planning a route, the app by default looks for the nearest road within a 350-meter radius of the point you specified. If no road is found within that distance, you can increase the search radius in the app settings.
Internet connection: an internet connection is required to create a route. Once the route has been generated, the simulation itself no longer needs a connection.

7. Saving and loading routes (GPX)

Save a route

You can save the route you created as a GPX file. While a route is on the screen, tap the Save route button at the bottom left of the map screen, enter a file name, then tap SAVE.

Load a GPX route file

You can also load an existing route in GPX format. First copy the route file to your device. Then tap the Load route button at the bottom left of the map screen and select the file. The route appears on the map as a blue line. You can simulate the virtual vehicle on a loaded route in the same way as described in the previous section.

8. App menu

All functions of the app can be reached through buttons and also through the app menu. The menu button (three vertical dots) is at the top left of the map screen. Its commands are:

  • Help
  • Legal Notices
  • Developer Info
  • Settings
  • Load route
  • Save route
  • Upgrade to Pro
  • Exit App

9. Location search

The app can search for a location by name or address, worldwide. An internet connection is required while you use it.

Tap the search button at the top right. A search bar appears where you can type the name or address you are looking for. The app finds it and positions the map there.

10. Settings

Tap the settings button (a wrench icon) at the top right over the map to open the settings screen. You can set these parameters:

  • Virtual vehicle speed – used when simulating movement along a route
  • Road search radius – used to find the road closest to the point you specified
  • Bluetooth NMEA output – ON / OFF
  • Startup animation – ON / OFF

11. Upgrade to Pro

The Upgrade to Pro button (a yellow star) is at the top left, right under the app menu button.
